Context Notes

Six moves and it makes sense

Everything you file, note and cite stays in this browser — no account, no server, no telemetry. The side panel lives behind the toolbar icon puzzle piece → pin Context Notes; the full dashboard is one click from there.

Each move hands you to the next — file a paper and the panel suggests highlighting it, highlight and it suggests tracking it, and so on. The Getting started list in the panel checks itself off as you go, from what you actually did.

  1. 1

    File a source

    Open the article page itself — not the search results; the panel will tell you when a page has nothing to file — and press File into project. When the page carries a DOI, the record is completed from the DOI registry: structured authors, year, journal, volume, issue, pages. Fix anything by hand later via Dashboard → Documents → Edit. If the panel says it has no access to a tab yet, press Allow reading pages — one prompt, revocable any time in Site access.

  2. 2

    Highlight what matters

    Press Annotate this page and allow the site once — the annotator loads only on sites you approve, and you can revoke any site under . Then select text and pick one of four highlight colours — your own code for "method", "key finding", "disagree", whatever you decide they mean. Add your words in the panel's note card whenever you like. Every highlight repaints, in its colour, on your next visit.

  3. 3

    Read PDFs the same way

    Dashboard → Documents → Add PDF opens the bundled reader: text highlights, drawn region anchors, notes and review statuses — all placed by page fractions, so they survive zoom and reload.

  4. 4

    Track your reading

    Every source moves To read → In review → Analysed → Used in output. Change it from the status chip on any row, or drag cards across the Kanban board on the dashboard’s Overview (arrow keys work too).

  5. 5

    Arrange your draft

    Dashboard → Outline is where you arrange it: every highlight starts in Unplaced, and you give it a Section — Introduction, Background, Evidence, Counter-arguments, Conclusion by default, or your own via Add section. Your sections cite in the order you arrange them, so this is where the essay actually takes shape. Click any passage to jump back to where you highlighted it. Nothing placed yet? The draft groups passages by highlight colour instead, until you assign one. takes you straight there.

  6. 6

    Cite without retyping

    Cite on a row copies an in-text citation; Copy bibliography compiles the project. Seven base styles — APA, Harvard (Cite Them Right and Solent University), Chicago ×2, MLA, Vancouver — or open the style editor and turn plain rules into your journal’s own format, with a live preview.

When you work with others

Team → Sync exports the whole project as one file — optionally password-encrypted — and an import always shows exactly what it would change before anything is written. Roles are advisory and the Team view says so plainly: with no server, every collaborator holds a full copy.

This guide stays available from the Guide button in the side panel.
